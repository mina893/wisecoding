와이즈코딩 3D 로봇 PC 테스트 (Python 설치 불필요)

1. ZIP 파일을 먼저 압축 해제합니다.
2. START_3D_TEST.bat 를 더블클릭합니다.
3. Windows 경고가 나오면 '추가 정보' > '실행'을 선택합니다.
4. 브라우저가 자동으로 http://localhost:8000/ 에 열립니다.
5. 테스트하는 동안 검은 PowerShell/명령 창을 닫지 마세요.
6. 종료하려면 검은 창에서 Ctrl+C를 누르거나 창을 닫습니다.

이 테스트 서버는 Windows에 기본 포함된 PowerShell을 사용하므로 Python 설치가 필요 없습니다.
